# EDA Project Report – Student Performance

## 1. Introduction
Exploratory Data Analysis (EDA) is the process of examining a dataset to understand its structure, identify patterns, detect unusual values, and discover relationships between variables.

## 2. Problem Statement
Analyze student-performance data and identify factors that are associated with final academic scores.

## 3. Objectives
- Understand the dataset using descriptive statistics.
- Examine distributions of important variables.
- Study relationships between academic and lifestyle variables.
- Measure correlations between numerical features.
- Present findings through clear visualizations.

## 4. Data Preparation
The dataset was checked for data types, duplicate records, missing values and basic statistical properties before analysis.

## 5. Analysis Performed
### Univariate Analysis
Histograms and summary statistics were used to understand individual variables.

### Bivariate Analysis
Scatter plots were used to examine relationships such as:
- Study Hours vs Final Score
- Attendance vs Final Score
- Assignment Score vs Final Score
- Sleep Hours vs Final Score

### Correlation Analysis
A correlation matrix and heatmap were used to identify numerical variables most strongly associated with Final Score.

## 6. Key Insights
The exact strength of relationships should be taken from the generated dashboard. Correlation indicates association, not causation.

## 7. Conclusion
EDA provides a practical way to convert raw student data into understandable insights. The dashboard makes it easier to explore patterns and communicate findings.
