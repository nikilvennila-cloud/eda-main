# Exploratory Data Analysis (EDA) Project

## Project Title
**Student Performance Exploratory Data Analysis**

## Objective
Analyze a student-performance dataset to uncover patterns and trends using statistical summaries and visualizations.

## Key Features
- Data loading and basic exploration
- Statistical summaries
- Missing-value and duplicate checks
- Distribution analysis
- Correlation analysis
- Relationship analysis between study habits, attendance, assignments, sleep and final score
- Interactive Streamlit dashboard
- Structured insights/report

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Dataset
The included `student_performance.csv` contains 500 sample student records.

## How to Run

```bash
python -m venv venv
```

Windows:
```bash
venv\Scripts\activate
```

Install packages:
```bash
pip install -r requirements.txt
```

Run:
```bash
streamlit run app.py
```
